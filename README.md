# 🌸 SAKURA

**A simple, focused task management app for everyday life and study.**

SAKURA is a native Android application designed to help users organize daily tasks and keep track of their progress in a clean, calm, and Persian-friendly interface.

## ✨ Features

- **Task Management** — Add tasks with a title and optional description.
- **Task Status Tracking** — Mark tasks as completed or in progress.
- **Progress Overview** — View task counts and completion progress on the home screen.
- **Offline-First Storage** — Store task data locally on the device.
- **Persian RTL Interface** — Designed for right-to-left Persian text.
- **Custom Visual Identity** — A warm, minimal interface inspired by the Sakura theme.

## 🛠️ Built With

- **Kotlin**
- **Jetpack Compose**
- **Material 3**
- **Room**
- **MVVM Architecture**
- **Kotlin Coroutines & Flow**

## 📱 Project Status

SAKURA is an ongoing personal Android development project. Its current focus is task management and daily study organization, with room for future improvements.

## 🚀 Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/morteza-rajabi-arch/SAKURA.git
   ```

2. Open the project in **Android Studio**.
3. Allow Gradle to sync.
4. Run the `app` configuration on an Android device or emulator.
